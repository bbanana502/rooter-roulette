# 루터 굿즈 룰렛

굿즈이벤트 포스터의 룰렛을 그대로 옮긴 현장용 룰렛. 빌드·설치 없이 순수 HTML/CSS/JS.

## 실행
```sh
./start.sh          # http://localhost:5173 이 열림 (종료: Ctrl+C)
```

## 조작
| 키 | 동작 |
|---|---|
| Space / Enter | 룰렛 돌리기 · 결과 닫기 |
| F | 전체화면 |
| S | 운영 패널 (우리 굿즈로 채우기, 통계) |
| Esc | 결과 닫기 |

- 왼쪽 입력창에 `이름*개수`를 쉼표·줄바꿈으로 적음. 예: `키링*27, 띠부씰*30, 간식*43` (개수 없으면 1개, 같은 이름은 합침)
- 입력한 개수 그대로 칸이 생김 (키링 1 + 간식 1 = 2칸, 합 100이면 100칸)
- 입력창 아래 칸 이름 버튼을 누르면 당첨 ↔ 간식이 바뀜 (처음엔 이름에 '간식'·'꽝'이 있으면 간식 칸으로 짐작). 같은 이름 칸은 전부 같은 설정
- 간식 칸에 걸리면 20% 확률로 '럭키 찬스! 한 번 더' → 버튼(또는 Space)으로 바로 다시 돌림. 1인당 한 번 (다시 간식이면 간식 2개)
- 입력을 고치면 같은 칸이 몰리지 않게 고르게 배치, '섞기'를 누르면 무작위로 섞음
- 돌리면 칸 하나가 똑같은 확률로 뽑힘(= 개수 비율). 당첨돼도 칸 개수는 줄지 않음
- 운영 패널(S): '우리 굿즈로 채우기'(아크릴 키링*27, 띠부씰*30, 간식*… → 간식 개수만 입력), 참여 통계
- 입력 내용 · 칸 순서 · 통계는 이 브라우저(localStorage)에 저장됨
